Overview

TOG defines a portable digital rights profile that can travel with a supported asset. The profile gives wallets, markets and applications a common way to read rights information.

Rights object

The rights object connects asset identity, rights data, control data and verification information in one readable profile.

identityasset, token, contract, chain
rightslicense, royalty, attribution
controltransfer, usage, revocation
proofsource, status, updated

Dimensions

The core profile contains six rights dimensions: License, Royalties, Attribution, Transfer, Usage and Status.

Verification

Each claim can be represented with a verification state. The prototype uses Verified Onchain, Verified from License and Reported or Inferred.

API surface

The application surface can resolve a complete profile or query an individual dimension using the asset identifier.

GET/v1/rights/{assetId}
GET/v1/rights/{assetId}/{dimension}
GET/v1/verify/{assetId}
